\subsection{Frozen dataset and study design}

The representation-training study uses the public
\href{https://huggingface.co/datasets/qpaig-mit/pixcell}
{\texttt{qpaig-mit/pixcell}} dataset, configuration \texttt{depth}, at
revision \texttt{v2.0.0}. The release contains 3{,}468 training rows and
1{,}092 held-out parameter settings over 546 representations. Each policy
receives the maximum-visibility component image, its physical footprint, and
the fixed \texttt{pixcell-direct-reconstruction-v2} programming contract.
Supervised stages use the corresponding primitive-only program as the target.
Target rasters, calibration, reference programs, representation labels, and
split metadata remain in the separately keyed \texttt{references}
configuration and never enter model messages.

The dataset revision is bound to a release manifest, while the complete
stage graph and every recipe are frozen in
\path{rl/studies/representation_training_v1/protocol.json}. Run manifests
and sampled programs are retained outside the repository under the
versioned \path{representation-training-v1} evidence root.

\subsection{Training paths}

The study tests five predefined hypotheses. RT-H01 applies one mixed
supervised pass to all 3{,}468 training rows. RT-H02 begins from the shared
L0 supervised checkpoint and adds L1 through L4 supervision sequentially,
resetting the optimizer at each level. RT-H03 begins from the same L0
checkpoint and learns L1 through L4 with geometry-rewarded reinforcement
learning. RT-H04 continues the mixed-supervised checkpoint with reinforcement
learning from its first unmastered level. RT-H05 applies a bounded L4
reinforcement-learning stage to Inkling. The protocol represents these paths
as \texttt{qwen-mixed-sft} followed by the first required stage from
\texttt{qwen-mixed-rl-l0} through \texttt{qwen-mixed-rl-l4};
\texttt{qwen-l0-sft} followed by
\texttt{qwen-sequential-sft-l1} through
\texttt{qwen-sequential-sft-l4}; \texttt{qwen-l0-sft} followed by
\texttt{qwen-l0-rl-l1} through \texttt{qwen-l0-rl-l4}; and
\texttt{inkling-l4-rl}.

The Qwen policy is Qwen3.6-35B-A3B with a rank-32 LoRA. Supervised training
uses batch size 64, Adam with learning rate $10^{-4}$, linear decay, one
physical pass, and loss only on the generated program and end token. Each
Qwen reinforcement-learning level permits at most 30 steps, with checkpoints
at steps 1, 5, 10, 15, 20, 25, and 30. Each step contains eight prompt groups
with four samples per group, a $10^{-5}$ learning rate, zero KL penalty, and
20\% replay from earlier levels. The reward is raw absolute-scale IoU after
deterministic execution and source verification. Inkling uses the same
four-sample grouping and learning rate for its bounded L4 path, with sealed
ceilings at steps 1, 6, and 14.

\subsection{Evaluation and final results}

The full held-out-parameter panel contains all 1{,}092
\texttt{depth/validation} rows. The F1--F8 progress panel uses one attempt per
figure, while the final benchmark uses four. A level is mastered only when
mean raw absolute-scale IoU reaches $0.80$ and the pure-executable rate
reaches $0.95$. Reference rasters and calibration enter only the evaluator
after a program has been sampled.
