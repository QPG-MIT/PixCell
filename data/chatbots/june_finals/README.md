# Curated reference examples

Hand-curated benchmark devices with documented baseline and agentic runs
(per-device `README.md` narratives, `metrics.json`, target masks, run scripts,
and the aggregate `SUMMARY_opus-4.8.md`). Harvested from the
[appliedphotonics/homi](https://github.com/appliedphotonics/homi) snapshot
(2026-06-12/13), which remains the archive for the full per-attempt render
PNGs (raster/overlay/diff images of every generation attempt) omitted here to
keep this repo lean.
